📊 Expense Tracker
A lightweight, terminal-based application to manage daily finances, developed in Python.

👤 About the Author
Developed by Aashik Pandit, a U-19 programmer and student passionate about building functional software solutions. This project is part of a dedicated focus on mastering Python development.

🚀 Features
Add Expenses: Quickly log expenses with date, category, and description.

Data Validation: Includes error handling for numeric inputs to prevent crashes.

View History: Display a formatted list of all recorded expenses.

Total Calculation: Automatically sums up all entries to show your total spending.

Clean Interface: Simple command-line menu for easy navigation.

🛠️ Tech Stack
Language: Python 3.x

Concepts Used: Lists, Dictionaries, While Loops, Try-Except blocks, and F-strings.
